# 📊 Calculadora de IRRF

Projeto desenvolvido em Microsoft Excel para organização e
automatização de informações relacionadas ao cálculo do IRRF.

## 🎯 Objetivo

Desenvolver uma ferramenta organizada para facilitar o cadastro,
consolidação e cálculo das informações utilizadas na apuração do IRRF.

## 🗂️ Estrutura do projeto

- 👤 Titular
- 📄 Informes
- 🧾 Notas Fiscais
- 👨‍👩‍👧 Dependentes
  
## 🛠️ Ferramentas

- Microsoft Excel
- Fórmulas e funções
- Validação de dados
- Tabelas
- Automatização de cálculos
